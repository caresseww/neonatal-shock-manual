① 基本概念｜新生儿循环特点

为什么不能照抄成人 · 休克五型因果链 · 核心数字与门槛
这页为什么重要：新生儿低血压不是一个病。同样 MAP 低，可能是血不够、泵没劲、血管松了、肺压堵了、血被分流偷走了——处理完全不同。先搞懂新生儿循环跟成人哪里不一样，后面看心超和选药才不会照抄 PICU 方案。

新生儿循环的 5 个发育特点（为什么不能照抄成人）

新生儿 / 早产儿
  • 未成熟心肌：肌节少、β1受体少、收缩储备差，后负荷稍增 CO 即降
  • 交感末梢缺如：间接释放去甲肾的药（多巴胺）效果打折
  • PVR 仍高：生后过渡需数天，PPHN 常见
  • PDA 开放：SVR 变化直接影响左向右分流
  • HPA 轴不成熟：相对肾上腺皮质功能不全常见
  • 脑自主调节范围窄：常压力被动，BP 低直接 = 脑灌注低
成人 / 儿童
  • 心肌储备充足，可耐受后负荷
  • 交感末梢完整，间接药作用充分
  • PVR 低、无分流
  • 无 PDA
  • 肾上腺功能完整
  • 自主调节成熟

（体循环被偷走）		 病因：<30周早产儿生后2–7天，导管没关

PPHN
（梗阻性）		 PVR↑
（肺血管堵了）		 病因：胎粪吸入、RDS、膈疝、肺发育不良
→ 肺血管没扩张 → 右室打血进肺的阻力↑ → 右室压力↑
→ 室间隔被推向左室（D字征）→ 左室充盈受限 → CO↓
→ 右心血经 PDA/PFO 右向左分流 → 动脉血氧↓（中央发绀）
→ 导管前（右上肢）SpO₂ > 导管后（下肢）差>10% 		D字征、TR>3m/s、PAP/SAP≥0.5、PDA/PFO右向左或双向分流、LPA峰值<20 cm/s 降 PVR + 提 SVR 减少右向左分流：iNO 5–20ppm + 去甲肾（α2→NO→顺便降PVR）；BP正常加米力农。米力农单独用在BP低时加重右向左分流
一句话记牢：低血容量=血不够→补液；心源性=泵没劲→强心；分布性=血管松→缩血管；PDA=血被偷去肺→关导管；PPHN=肺堵了→降PVR。五条路，五个方向，不能走错。

核心数字（不是目标，是门槛）

MAP ≥ GA
MAP（平均动脉压）≥ GA（胎龄周数）
28周≥28 mmHg，32周≥32
SVC <55
SVC（上腔静脉血流量）
mL/kg/min = 脑灌注不足
RVO <150
RVO（右室输出量）
mL/kg/min = 低心排
LPA <20
LPA（左肺动脉峰值流速）
cm/s = 肺血流受阻
真正目标：CRT（毛细血管再充盈时间）<3s · 乳酸正常 · 尿量>1 mL/kg/h · 四肢温暖
最重要的一句话：MAP ≥ GA ≠ 灌注足够。Seri 2004：ELBW 生后第一天正常 MAP 仍可伴 SVC 低流量，且与死亡/伤残相关。先看流量，再看压力。

为什么新生儿一线是多巴胺，不是去甲肾？

成人脓毒症是血管麻痹——心能代偿，直接补 SVR 即可（去甲肾是成人指南一线）。

新生儿是多因素混合，床旁分不清"心不行"还是"血管松"。多巴胺兼顾 β1 强心 + α 加压，是诊断不明时的合理起点；直接上去甲肾，若实际是心源性，后负荷↑让 CO 更差。

但不是教条：PPHN 时去甲肾反而是优选（α2→NO→降 PVR）；<28 周儿交感末梢缺如，肾上腺素直接激动更可靠；Garegrat 2023 RCT 显示新生儿感染休克一线去甲肾也安全。

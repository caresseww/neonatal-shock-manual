新生儿休克与血管活性药物 · 床旁整合手册

复旦儿科 NICU · 基本概念 → 值班决策 → 药物 → 心超词典 → 文献 · 手机阅读版
这页为什么重要：新生儿低血压不是一个病。同样 MAP 低，可能是血不够、泵没劲、血管松了、肺压堵了、血被分流偷走了——处理完全不同。先搞懂新生儿循环跟成人哪里不一样，后面看心超和选药才不会照抄 PICU 方案。

新生儿循环的 5 个发育特点（为什么不能照抄成人）

新生儿 / 早产儿
  • 未成熟心肌：肌节少、β1受体少、收缩储备差，后负荷稍增 CO 即降
  • 交感末梢缺如：间接释放去甲肾的药（多巴胺）效果打折
  • PVR 仍高：生后过渡需数天，PPHN 常见
  • PDA 开放：SVR 变化直接影响左向右分流
  • HPA 轴不成熟：相对肾上腺皮质功能不全常见
  • 脑自主调节范围窄：常压力被动，BP 低直接 = 脑灌注低
成人 / 儿童
  • 心肌储备充足，可耐受后负荷
  • 交感末梢完整，间接药作用充分
  • PVR 低、无分流
  • 无 PDA
  • 肾上腺功能完整
  • 自主调节成熟

为什么新生儿一线是多巴胺，不是去甲肾？

成人脓毒症是血管麻痹——心能代偿，直接补 SVR 即可（去甲肾是成人指南一线）。

新生儿是多因素混合，床旁分不清"心不行"还是"血管松"。多巴胺兼顾 β1 强心 + α 加压，是诊断不明时的合理起点；直接上去甲肾，若实际是心源性，后负荷↑让 CO 更差。

但不是教条：PPHN 时去甲肾反而是优选（α2→NO→降 PVR）；<28 周儿交感末梢缺如，肾上腺素直接激动更可靠；Garegrat 2023 RCT 显示新生儿感染休克一线去甲肾也安全。

升级路径（六步）

1. 心超四步定表型，不要只看 MAP
2. 纠正可逆因素：pH<7.2、离子钙<1.0、低糖、低温、贫血
3. 试扩容仅低血容量：10 mL/kg；无改善不重复第三次
4. 按表型一线药，每15–20min滴定，1h复评心超
5. 阶梯升级：多巴胺>10–20 → 氢化可的松 → 肾上腺素(<28周)/去甲肾(PPHN) → 加压素
6. 早撤：24–48h过渡完成后逐步减量
打图顺序：先剑突下（保命）→ 胸骨旁（PLAX→PSAX）→ 心尖（测 SAVV/TR）→ 胸骨上窝（PDA）。10 分钟出结论，不追求完美测量。

1. 剑突下四腔心 第一步，先看整体
四腔心解剖+超声对照。
低血容量时：LV 小而收缩过度（hyperdynamic），心内膜收缩期几乎贴一起。
手把手（新手按这个做）：
  1. 开机：选 Cardiac / Neonatal preset，深度调到 4–6 cm（早产）或 6–8 cm（足月）
  2. 探头：小圆阵探头（新生儿专用），涂足量 gel，探头轻放不要压
  3. 位置：探头横放剑突下（胸骨最下端下方），标记点朝左肩
  4. 找图：先看到肝脏（一片灰），然后轻轻向上翘探头（扇形朝心脏方向扫），等四个腔室突然出现
  5. 对了的标志：屏幕上方看到右房右室，下方看到左房左室，室间隔在中间竖条
看到什么 → 怎么判断：
  • 两室都小、收缩期心内膜快贴一起 → 低血容量，去补液
  • 右室比左室大、室间隔被推 → 右心压力高，走 PPHN 流程
  • 心脏外面一圈黑水 → 心包积液，红旗，立即叫会诊
2. PLAX 胸骨旁长轴 测 FS、LA/AO
PLAX：超声图（左上）+ 心脏解剖对照。RVOT→AO→LA 一线排列，MV 在中间。
手把手：
  1. 位置：探头放左胸骨旁第 2–3 肋间（乳头上方一点），标记点朝右肩
  2. 找图：探头轻贴胸壁，不要压；左右微微摆动，直到屏幕上看到 RVOT（流出道）→ AO（主动脉根）→ LA（左房）排成一条水平线
  3. 对了的标志：主动脉根像一个"甜甜圈柄"在中间，二尖瓣在下方，左房在主动脉后面
怎么量 FS：
  • 按 M-mode 键，把取样线（竖线）放在二尖瓣腱索水平（不要放乳头肌），垂直穿过室间隔和左室后壁
  • 屏幕上出现两条波浪线 = 室间隔和左室后壁的运动轨迹
  • 在舒张末期（室间隔最靠右 = 心脏最大时）量 LVIDd
  • 在收缩末期（室间隔最靠左 = 心脏最小时）量 LVIDs
  • FS = (LVIDd − LVIDs) / LVIDd × 100%
正常值：28–38%。<28% = 泵没劲（心源性休克）。
怎么量 LA/AO：在 PLAX 2D 图上，舒张末期量主动脉根内径（AO）和左房前后径（LA），比一下。>1.3 = 左心被 PDA 灌大。
3. M 模式测 FS 怎么量
M 模式：LVIDd（舒张末）和 LVIDs（收缩末）。FS=(d−s)/d。
关键坑：
  • 取样线必须垂直室间隔，放在二尖瓣腱索水平，不要放乳头肌
  • 低血容量时 FS 假性正常——小腔室收缩幅度看起来大，必须看 SAVV 才知道每搏量
  • FS 正常但 SAVV 掉了 = 心功能开始不行
4. PSAX 胸骨旁短轴 看 D 字征
探头位置：探头在胸骨旁垂直于室间隔，LV横切。
正常：LV圆形，RV在左包绕。
D字征：室间隔扁平=PPHN。
手把手：
  1. 位置：探头位置跟 PLAX 一样（左胸骨旁肋间），但顺时针转 90°，标记点朝左肩
  2. 找图：转完后 LV 从"长条"变成"圆圈"——像切面包圈一样横切左室
  3. 对了的标志：左室在屏幕右边像个圆面包圈，右室在左边像个月牙包绕着它
看什么（不用量，看形状）：
  • 正常：LV 是正圆形，室间隔在中间弯向 RV（小弧线）
  • D 字征：室间隔变平，LV 被压成 D 形 = 右室压力 > 左室（PPHN）
  • 整个心动周期都扁平 = 持续 PPHN；只有舒张期扁平 = 容量过负荷
5. SAVV / SVC 血流 最可靠的每搏量
心尖四腔心探头位置：探头放心尖搏动处，标记点指向左腋下。
SVC 血流测量。左：测直径；右：PW 频谱。SVC>55 mL/kg/min。
手把手测 SAVV（主动脉瓣 VTI）：
  1. 位置：探头放心尖搏动处（左锁骨中线第 4–5 肋间），标记点朝左腋下
  2. 找图：心尖四腔心（四个腔室都看到），然后把探头向上翘 15°，露出主动脉瓣 = 心尖五腔心
  3. 打 PW：取样容积（小门）放在主动脉瓣开口处（刚过瓣叶，不要在左室里）
  4. 包络：屏幕上出现一个三角形频谱（收缩期向上），用 trace 功能沿三角形上缘描一圈
  5. 读出 VTI：机器自动给一个数字，单位 cm
判断：
  • SAVV ≥ 5–6 cm = 每搏量正常
  • < 4.5 cm = 每搏量下降（不管 FS 好不好，都是低心排）
  • 为什么必须看这个：低血容量时 FS 假性正常，但 SAVV 已经掉了
6. PDA 彩色多普勒 胸骨上窝
胸骨上窝切面：主动脉弓长轴，标注升主动脉/弓/降主动脉分支。
26 周早产儿 PDA：红色射流从主动脉射入左肺动脉。
看四个数：
  • 导管直径 >1.5 mm = hsPDA
  • 左向右分流 = 肺充血、体循环窃血
  • 右向左分流 = PPHN
  • 降主动脉舒张期反向血流 = 严重窃血
体位：胸骨上窝，声束指向主动脉弓长轴
7. TR 连续波多普勒 估 PASP
心尖四腔心：从心尖打，四个腔室都看到，TR 从这里打 CW。
TR CW：v=3.52 m/s，4v²≈50，加 RAP 5 ≈ PASP 55。
手把手测 TR 速度：
  1. 位置：心尖四腔心（同 SAVV 那个位置）
  2. 找 TR：打开彩色多普勒，三尖瓣口看到蓝色（或黄色）射流 = TR
  3. 打 CW：把连续波取样线沿着这束射流的方向放，尽量平行
  4. 读速度：屏幕上一个抛物线波形，量峰值速度 v（m/s）
怎么算 PASP：
PASP = 4 × v² + RAP
例：v = 3.5 m/s → 4 × 3.5² = 4 × 12.25 = 49；RAP 估 5（正常）→ PASP ≈ 54 mmHg
  • TR < 2.5–3 m/s = 正常
  • TR > 3 m/s + D 字征 = PPHN
  • PAP/SAP ≥ 0.5（PASP ÷ 收缩压 ≥ 0.5）= 肺压偏高
8. 心包积液（红旗）看到立刻穿刺
大量心包积液（白箭头）+ 右房舒张期塌陷（红箭头）= 填塞。
识别要点：
  • 心外膜和心包之间一圈无回声（黑色）暗区
  • 右房/右室舒张期塌陷 = 填塞（不是积液量的问题，是压不住了）
  • 心脏在积液里摆动
这不是加药能解决的：立即心包穿刺，叫心外科/心超会诊。

高频坑

  • 只盯血压：MAP ≥ GA ≠ 灌注足够；ELBW 正常 MAP 仍可 SVC 低流量
  • "肾剂量多巴胺"：新生儿 5 μg/kg/min 已出 α 效应，不存在
  • 多巴酚丁胺升 BP：它改流量不改压力，BP 不升但 CO 上去就是有效
  • 米力农当急救药：起效 30–60 min，BP 低时禁用
  • 激素常规加：治疗前皮质醇>15 者加激素死亡 OR 26.3（Peeples 2017）
  • 照搬 PICU 剂量：去甲肾 0.05–0.5，不是 2
  • 忽视可逆因素：pH<7.2、离子钙<1.0、低糖、低温未纠正，药无效

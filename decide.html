⚠ 临床只能粗筛，不能确诊：
低血容量和心源性早期都四肢凉+CRT↑；分布性和PDA都脉压宽；光靠病人外表分不开。 下表只是帮你带着问题去打心超——看到四肢暖+脉压宽，重点查PDA；看到发绀+导管前后差，重点查PPHN。最终诊断必须靠心超。

口诀：看到什么 → 心超先查什么

临床表现最可能心超重点看
四肢凉 + CRT↑ + 苍白 + HR代偿快 低血容量 或 心源性 先看两室大小：小而收缩过度=低血容量；大小正常但运动弱=心源性。再看FS/SAVV
四肢暖 + 脉压宽 + CRT正常 分布性（血管扩张） 心功能应该好；如果FS好但BP低→缩血管。但要先排除PDA（也是脉压宽）
脉压宽 + bounding pulse + 肺充血 + 舒张压低 PDA 窃血 胸骨上窝彩色多普勒看导管直径；PLAX测LA/AO（>1.3）；降主动脉舒张期反向血流
中央发绀 + SpO₂难维持 + 导管前后差>10% PPHN PSAX看D字征；心尖四腔打TR CW（>3 m/s）；PDA分流方向
肝大 + 肺啰音 + 补液后BP不升 心源性 PLAX测FS<28%；心尖五腔测SAVV<4.5cm；Tei指数
BP骤降 + 心音低 + 奇脉 心包填塞 剑突下四腔心看心包无回声暗区 + 右房舒张期塌陷→立即穿刺
MAP（平均动脉压）低于胎龄周数 / 灌注差 / CRT>3s / 乳酸高
